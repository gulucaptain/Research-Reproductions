# Evidence policy

This is a collection of independent reproductions, not official author implementations. The project registry is a reviewed snapshot. It distinguishes implemented components, executed experiments, observed trends and specific numerical matches.

- Keep unfavorable seeds, failed cases and missing components visible. Never replace a failed formal run with a successful altered configuration without identifying the change.
- Report metrics only within their original evaluation definition. PSNR AUCs, tracking metrics and IoUs from different projects are not comparable.
- Local engineering experiments and scale-reduced datasets do not establish original-paper table reproduction. Apple GPU timings do not establish NVIDIA kernel speedups.
- Link precise source evidence pinned to a Git commit. Live GitHub links help exploration; pinned links support the claim as reviewed.
- The copied preview must be unchanged, have a recorded digest, and retain a caption describing scope. Figure excerpts may include source data for research comparison; do not treat those excerpts as newly licensed data.
- An update requires reading the new result and its limitations. The collection generator checks structure, hashes and reproducible output; it does not audit numerical correctness of an upstream algorithm.

As of 2026-11-16, all six initial projects retain the status Partial reproduction.
