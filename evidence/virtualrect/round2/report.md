# VirtualRect R2：两层初始化、多种子与模块有效性

审阅日期：2026-11-17。结论：**两层初始化已可运行并通过反传检查；当前 A1 风险权重没有稳定有效的证据，虚拟相机头在本轮评估上总体有害。** 这否定的是当前独立假设版在这个小样本设置中的收益，不是对原论文方法的普遍否定。

## 先固定的实验范围

本轮没有下载任何数据或权重，继续用7对已取得的官方Carla图像。先写入 `results/round2/protocol.json`，再查看初始化/消融结果。

- 本轮训练：00001617、00003715、00008004、00008363。
- 本轮留出：00008521、00009691、00069529。
- 五个种子：0、1、2、3、4。种子同时控制风险头初始化、采样顺序和RANSAC；同一种子所有权重方法共用同一匹配和内点集。
- **七对都属于官方训练划分，而且上一轮已查看过全部七对。** 这里只能称本轮内部留出，不能称官方测试或未见场景泛化；15个“种子×图像”不是15个独立场景。
- 初始化选择只看四对训练图，512×256。消融在1024×512上冻结选中的匹配器，缓存其描述符和对应点，隔离新增模块作用；不是端到端重新训练匹配器。
- 风险头训练120步Adam、lr=1e-4；相机头另120步。每4步覆盖一次四个训练样本，顺序按种子打乱。固定最终步评价，不按留出表现选检查点。几何用CPU float64，头部float32；所有模型参数与原始日志留存。

## 两层初始化解决了什么

“两层”沿用当前假设：两组self/cross，共四个attention block。原作者术语仍待确认。对原始四组检查点的六种有序保留组合做完整枚举，不降低原始匹配阈值。

| 保留原始组（从1计数） | 四对训练图的匹配数 | 各图GT行残差中位数的中位数(px) |
|---|---|---:|
| 1+2 | 0 / 0 / 0 / 0 | 不可用 |
| 1+3 | 0 / 0 / 0 / 0 | 不可用 |
| 1+4 | 1204 / 1324 / 1082 / 1158 | 0.2246 |
| 2+3 | 0 / 0 / 0 / 0 | 不可用 |
| 2+4 | 1062 / 1157 / 852 / 1047 | 0.2319 |
| 3+4 | 957 / 855 / 738 / 871 | 0.2563 |
| 完整四组控制 | 1147 / 1337 / 1039 / 1164 | 0.2016 |

按“可用图像数优先，其次GT行残差”的预设规则选择**1+4**。结果指向保留末组对预训练输出分布的重要性，但尚未证明具体内部原因，也不是作者两层检查点。重映射实现与原模型显式抽取模块在CPU上的匹配输出逐项相同，最大差0。

1024×512下七对都有匹配，三对留出分别3885、4407、4206个。选定两组后，完整训练链路也通过：Stage1后两次1.303/1.161s，Stage2为0.493/0.486s；最大采样live内存约4.58GiB。各阶段梯度有限、预期模块有非零梯度。该测量只验证可训练性，不是收敛或两层优于四层的证据。

## 第一组：风险权重消融

固定匹配器后比较单位权重、外观置信度、未训练风险头、仅NIG训练、NIG+H训练、打乱学习权重、学习权重均值等控制。每种控制共用同一种子的RANSAC初始化和内点集合，始终使用全部内点。常数均值控制可以排查“统一改变权重尺度/阻尼”等效应；打乱控制保留权重分布，破坏权重与观测的对应关系。

主评估对每一帧/种子取全部10种方法的共同有效参考像素，再计算MAE。参考仍是已知位姿校正后的SGBM预测，**不是真实深度，也没有换成论文DLNR/MonSter++后端**。像素先重投影到固定参考网格，再比较参考相机光轴方向的深度。另报告完整HW分母的正视差覆盖率与硬有效支持。

| 方法 | 五种子平均MAE ± 样本SD (m) | 平均覆盖率 |
|---|---:|---:|
| 单位权重 | 6.1909 ± 2.8560 | 59.66% |
| 外观置信度 | 6.2958 ± 3.2549 | 60.07% |
| 未训练风险头 | 6.1921 ± 2.8527 | 59.64% |
| 风险头：仅NIG | 6.1810 ± 2.8656 | 59.72% |
| 风险头：NIG+H | 6.1803 ± 2.8658 | 59.70% |
| 打乱学习权重 | 6.1921 ± 2.8605 | 59.79% |
| 常数学习权重均值 | 6.1909 ± 2.8560 | 59.66% |
| 风险头+相机头 | 6.2232 ± 2.8466 | 59.08% |
| 单位权重+相机头 | 6.2364 ± 2.8346 | 59.00% |
| 风险头+去掉support的相机头 | 6.2167 ± 2.7786 | 57.62% |

每个种子的值先对三帧等权平均，SD来自五个种子。**大SD不等于学习头不稳定的全部来源**：单位权重的对应图像/匹配固定，变化来源是RANSAC；另有跨种子公共掩码不同的问题，下面进一步统一了所有种子的掩码。

配对结果：

- NIG+H对单位权重：平均变化 −0.0106m，配对SD0.0243m；仅3/5种子改善，9/15帧-种子改善。
- NIG+H对仅NIG：−0.0007m，配对SD0.0027m；3/5种子改善。不能说H监督贡献已验证。
- NIG+H对打乱权重：−0.0118m，配对SD0.0552m；仅2/5种子改善。尚无稳定的观测相关权重优势。
- 学到的权重与GT残差绝对值的Spearman相关约−0.113到+0.069，关联弱且部分方向相反。

训练损失在五个种子都下降，H项确实给utility输出q提供非零梯度，只有NIG时q梯度严格为0。实现并非“没有梯度”，但**训练损失下降没有转化为可靠的留出深度收益**。

## 第二组：虚拟相机与覆盖

相机头使MAE平均增加0.0428m（配对SD0.0641m），只有2/5种子改善。覆盖率59.70%→59.08%，硬共同支持90.90%→89.78%。去掉support后硬支持进一步降至87.40%，正视差覆盖57.62%；support项确实限制了损失，但并未保证深度改善。

学习的eta均为负，约−0.01689至−0.00183。使用独立的SIFT对应点（按GT行残差<0.75px筛选，不参与当前LoFTR拟合）检查：风险头的平均行残差约0.13547px；相机头前后除去exp(eta)缩放后最大差4.24e-9px。也就是说，相机改变了尺度和采样，没有进一步改善相对行对齐；不应把缩小后的像素残差当作几何更准。

## 结果出现后增加的核验：跨种子固定掩码与恒定相机

看到初轮结果后，另写 `audit-protocol.json` 固定以下诊断，保留上面的主结果，不重新调参：

1. 同一帧对五个种子、所有主方法和两个附加控制取同一公共像素集合。
2. 固定相机控制：取每个种子**四帧训练图**的相机输出平均eta/shift，直接用于留出图，不用留出表现选参数。
3. 旧K控制：与学习相机完全相同的图像和重投影几何，只在视差转深度时错误使用旧fx。

共同集合为167680、197968、170775像素，分别仅占全图31.98%、37.76%、32.57%。因此这是保守交集上的诊断，不能替代全图覆盖报告。

| 方法 | 固定全种子公共掩码MAE (m) |
|---|---:|
| 单位权重 | 5.22875 |
| NIG+H风险权重 | 5.21204 |
| 风险+学习相机 | 5.25887 |
| 风险+训练平均固定相机 | 5.26060 |
| 风险+学习相机但误用旧K | 5.41992 |

风险对单位权重改善0.01671m，仍只有3/5种子改善。相机对风险基线增加0.04682m，**五个种子全部变差**。学习相机与训练均值相机仅相差0.00173m，没有证据证明当前条件化特征优于简单全局相机。误用旧K比正确K*差0.16106m，支持相机一致性的几何要求，不支持“学习相机头必然有收益”的更强结论。

统一掩码后单位权重五种子SD仍为2.65561m，其变化来自本地16次数字RANSAC。求解器稳定性是比当前权重增益更大的问题；本轮没有通过挑选种子或扩大RANSAC次数来掩盖它。

## 核验、保存与局限

- 检查点层重映射等价：最大输出差0；参考网格深度自比较最大误差7.54e-6m（float32重采样量化）；NIG-only/H损失的q梯度路径均符合预期。
- 五个种子、10种主方法、15个帧-种子组合均完成，无失败组合被排除。原始损失日志、最终头部检查点、相机矩阵、掩码hash和各方法指标都保留。全种子公共掩码及深度数组在本地data/round2/audit/。
- 数学定义仍采用A1独立假设；仅120步、四个训练样本，无法排除训练不足或假设不当。冻结匹配器的模块消融不等价于论文端到端训练。
- 下一步应先审查/稳定受约束RANSAC与重拟合，再针对权重公式、风险目标和相机目标设计更有辨识力的实验。当前不应宣称新增模块已复现成功，也没有理由启动全量数据下载。
